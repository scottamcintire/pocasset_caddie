# Pocasset Greens — on-course test app

Live at: https://scottamcintire.github.io/pocasset_caddie/greens-test/

- All 18 approved green renderings, shown upright along each hole's approach line.
- Type today's ezLocator pin for each hole (or all 18 at once). Pins are stored on the phone for today only.
- Live GPS yardage to the flag and to the front / center / back of the green (same method as V2.2.1).
- Works offline after the first load; add to the iPhone Home Screen from Safari.

This is a separate test. It does not change the main V2.2.1 app at the site root or `hold2-test/`.

Built 2026-10-26 12:31 from the master archive (`Pocasset_AI_Master/03_greens/hole_NN/approved/`): pin model (points + t) taken verbatim from each approved `index.html`; images are WebP copies of the approved 2× masters (long side ≤ 1600 px). Estimates only — not surveyed. Imagery derived from GolfLogix heat maps; course mapping © OpenStreetMap contributors (ODbL 1.0).
